# Prismas, Etiquetas e Cardápio

Gerador de prismas de mesa, etiquetas adesivas e cardápios em triângulo para visitas e delegações.

Abra o site, cole a lista de autoridades e baixe o PDF pronto para imprimir (escala 100%).

Os nomes digitados ficam só no navegador de quem usa; nada é enviado para servidor.
